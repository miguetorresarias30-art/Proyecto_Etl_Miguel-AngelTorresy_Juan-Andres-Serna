# Datos

El archivo `videojuegos_playstation.csv` es un conjunto de trabajo basado en un dataset público de ventas de videojuegos. Para el proyecto se usan registros de plataformas PlayStation y se conservan algunos problemas de calidad para que el pipeline pueda demostrar la fase de transformación.

Fuente de referencia:
- Starquell, `video_games_sales.csv` (GitHub Gist), basado en un conjunto de datos de ventas de videojuegos.

El archivo CSV local no se debe subir al repositorio según la guía del proyecto. Está incluido inicialmente para ejecutar la práctica, pero `.gitignore` evita que quede versionado.
